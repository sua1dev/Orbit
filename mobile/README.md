# Orbit Mobile 0.2.0-alpha.2

Orbit의 Android용 개발 빌드입니다. Android 10(API 29) 이상에서 실행하며, 기기에 설치된 Android System WebView를 사용합니다.

시작 화면과 탭 화면의 **바로가기**에는 스페이스마다 아이콘 슬롯 6개가 있습니다. 빈 칸을 누르면 사이트를 넣을 수 있고, 아래의 **링크 추가**와 **폴더 추가**로 목록을 늘릴 수 있습니다. 편집 버튼이나 길게 누르기로 기존 항목을 수정합니다.

- 하단 주소창에서 URL을 열거나 Google, 네이버, DuckDuckGo로 검색합니다.
- 하단 탭 버튼에서 카드를 가로로 넘기고, 제목과 주소로 검색하고, 닫은 탭을 복원합니다. 탭 버튼을 길게 누르면 검색창과 함께 새 탭이 열립니다. 하단 도구 모음을 가로로 밀어서 열린 탭 사이를 이동할 수 있습니다.
- 설정의 검색 엔진, 테마와 배경 선택은 Orbit 안의 설정 화면에서 표시합니다. 시작 페이지는 서울 날씨와 시각에 따라 배경을 바꾸며 낮·밤·비·눈, 단색과 개인 사진을 선택할 수 있습니다.
- 메뉴의 **분할 화면**에서 두 탭을 선택할 수 있습니다. 두 페이지 사이의 구분선을 움직여 크기를 조절하세요. **새 시크릿 창**은 일반 WebView 저장소와 분리되어 열립니다.
- 탭 화면에서 즐겨찾기, 고정 탭, 색상 그룹을 확인합니다. 탭 카드를 길게 눌러 관리할 수 있습니다. 분리 로그인 스페이스에는 멀티 프로필을 지원하는 WebView가 필요합니다.
- 페이지 메뉴에서 즐겨찾기, 주소 복사, Android 공유, 앞뒤 탐색, 새로고침을 사용할 수 있습니다. 링크를 길게 누르면 새 탭에서 열 수 있습니다.
- 일반 탭의 주소와 즐겨찾기, WebView의 영구 쿠키와 사이트 데이터는 기기에 저장됩니다. Android 기본 앱 설정에서 Orbit을 웹 링크를 여는 브라우저로 선택할 수 있습니다.

이 빌드는 테스트용 디버그 키로 서명합니다. 앱을 다시 시작하면 일반 탭과 분할 화면의 마지막 주소가 복원됩니다. 지원 범위와 플랫폼별 차이는 [Windows 기능의 Android 지원 현황](WINDOWS-PARITY.md)을 확인하세요.

## 빌드

JDK 17 이상과 Android SDK Platform 36을 설치하고 Android Studio에서 `mobile` 폴더를 엽니다. Windows에서는 같은 폴더에서 다음 명령을 실행할 수 있습니다.

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

APK는 `app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다. Gradle은 저장소의 `renderer`에서 Orbit 아이콘, 사이트 아이콘과 배경 이미지를 복사합니다.
