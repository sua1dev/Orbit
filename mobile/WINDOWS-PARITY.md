# Windows 기능의 Android 지원 현황

대상은 Orbit Windows 1.4.7과 Orbit Mobile 0.2.0-alpha.1입니다.

## Android에서 사용할 수 있는 기능

- **탭과 작업 공간** · 탭 카드와 목록, 탭 검색, 고정·복제·순서 이동, 색상 그룹의 생성·편집·접기·해제, 닫은 탭 검색과 복원. 스페이스 간 탭 이동과 쿠키 분리는 멀티 프로필을 지원하는 Android System WebView가 필요합니다.
- **분할과 탐색** · 두 탭 동시 표시, 위아래·좌우 방향, 드래그로 비율 조절, 활성 영역과 주소창 연동, 분할 상태 복원. 모바일 웹 패널은 보조 페이지를 두 번째 영역으로 엽니다. 새 탭, 뒤로·앞으로, 새로고침, 길게 눌러 링크 열기·복사·공유, 사용자 동작으로 열린 웹 팝업을 지원합니다.
- **시크릿** · 별도 앱 프로세스와 WebView 데이터 디렉터리, 메모리 탭 상태, 일반 기록·자동완성 미사용. 정상 종료 시 임시 디렉터리 정리를 요청하고, 강제 종료로 남은 임시 디렉터리는 다음 Orbit 실행 때 정리합니다. Android 다운로드로 저장한 파일은 다운로드 폴더에 남습니다.
- **꾸미기** · 밝기, 스페이스 색상, 강조색, 간격, 모서리, 프리셋, 애니메이션, 주소창 위·아래, 탭 카드·목록, 태블릿 탭 라이브러리의 방향·너비, 도구 표시 옵션, 새 탭 자동 검색. Windows의 위쪽·세로 탭 배치는 Android의 카드·목록으로 대응합니다.
- **시작 페이지** · 서울 날씨·시각 자동 배경, 낮·밤·비·눈·단색·개인 사진, 밝기 조절, 시계, 바로가기, 최근 방문. 날씨 조회를 끄거나 연결되지 않으면 서울 시각으로 낮·밤을 표시합니다. 꾸미기 JSON을 Windows와 주고받을 수 있으며, 양쪽에서 공유하는 항목에 동일한 값이 적용됩니다.
- **검색과 보관** · Google·네이버·DuckDuckGo, 주소창 자동완성, 선택형 Google 추천, 스페이스별 검색과 방문 기록, 즐겨찾기 이름·주소 편집, HTML·Chromium JSON 가져오기, 일반 탭·즐겨찾기 JSON 내보내기.
- **페이지 도구** · 페이지 내 찾기, 글자 크기와 핀치 확대, 데스크톱 사이트 요청, Android 다운로드, 공유, 인쇄 및 시스템 PDF 저장. Android 기본 브라우저 역할과 Android 비밀번호 자동완성 서비스 설정을 사용할 수 있습니다.
- **영상과 카드** · 지원 기기에서 전체 화면 영상을 홈으로 나갈 때 Android Picture-in-Picture로 이어 봅니다. 내 Orbit 카드는 표시 이름과 소개를 편집하고 PNG로 저장할 수 있습니다.

## 구현 방식이 달라 추가 작업이 필요한 기능

- Electron의 압축 해제 Chrome 확장 API, 팝업·확장 관리자, Discord Custom RPC 호환 연결과 Windows의 개발자 도구 UI는 Android System WebView에 대응하는 API가 없습니다. 앱 안의 확장 호환은 별도 엔진이나 지원 범위를 정해야 합니다.
- Windows DPAPI 비밀번호 보관함과 Android 자동완성은 별개로 저장됩니다. 브라우저 안의 독립 Android 보관함과 안전한 이관 형식은 추가 개발 대상입니다. Google 로그인과 보호 영상은 사이트의 WebView 지원 정책을 따릅니다.
- Windows의 독립 일반 창, 개별 파일 기본 앱 연결, 페이지 전체 배율, 사이트별 음소거·권한, 탭의 전체 뒤로·앞으로 기록 복원, URL·파일 오프라인 연결과 영상 자동 PiP의 모든 전환 조건은 이 빌드에서 일부만 대응하거나 추가 개발이 필요합니다. Android는 웹 링크의 기본 앱 역할, 화면 분할, 글자 배율과 전체 화면 영상 PiP를 제공합니다.
- 브라우저 탭·비밀번호 기기 간 동기화와 Arc 원본의 폴더 구조를 유지하는 가져오기는 후속 제안입니다.
