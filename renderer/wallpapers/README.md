# 서울 새 탭 배경

첨부 남산 사진을 구도 참고 이미지로 사용해 Codex 기본 이미지 생성 도구에서 네 장을 만들었습니다. 브라우저에는 1672×941 JPEG로 저장합니다.

공통 프롬프트는 남산의 높은 시점에서 서울 시가지와 숲을 내려다보고, 화면 오른쪽에 N서울타워를 배치한 16:9 사진입니다. 글자나 인터페이스 없이 실제 풍경처럼 표현하도록 요청했습니다.

- 낮 — 맑고 푸른 하늘, 부드러운 구름, 오전 햇살과 푸른 숲.
- 밤 — 짙은 청색 하늘과 보랏빛 지평선, 불이 켜진 N서울타워와 서울 야경.
- 비 — 실내에서 닫힌 유리창 너머로 보이는 빗속의 서울. 유리에 흐르는 빗방울과 창밖의 남산타워.
- 눈 — 눈 덮인 소나무와 지붕 위로 눈송이가 내려오는 겨울 남산. 따뜻한 도시 조명.
